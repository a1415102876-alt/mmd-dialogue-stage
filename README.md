# MMD 对话舞台 MVP

通过 SillyTavern 静态服务打开 `/mmd-dialogue-stage/`。

## 使用方式

1. 点击“选择 PMX 模型文件”，直接选择 `.pmx` 文件；如果贴图不在同一目录，可再点击“补充贴图文件夹”。
2. 导入一个或多个 `.vmd` 动作文件。
3. 在动作库中点击动作，或通过“指令”页执行 JSON。

```json
{
  "expression": "happy",
  "intensity": 0.8,
  "action": "wave",
  "morphs": {
    "照れ": 0.35
  }
}
```

动作 ID 默认来自 VMD 文件名：`Wave Hand.vmd` 会转换为 `wave-hand`。Three.js 和 MMDLoader 已随页面放在本地，不依赖 CDN。物理、口型、持久化动作库和 SillyTavern 消息桥不在当前版本范围内。

## 学马仕风格

选择完整 `Texture2D` 文件夹与匹配的 PMX 后，在渲染预设中选择“学马仕风格”。更新版本后请刷新页面并重新载入模型、贴图和动作。

灯光面板下的“学马仕材质检查”可查看逐材质绑定，或切换基础颜色、Shade、Def、Ramp、皮肤遮罩和光照输入。贴图缺失、同名冲突与尚未启用的算法会明确显示，不会跨角色借用第一张图。

主光角度控制视角相关光照。学马仕材质检查面板有两个默认关闭的试验开关：角色专用阴影采样、眉眼半透（HairCover）。前者额外采样角色阴影灯深度图。后者执行“基础场景 → 仅 m_hir 面组补绘 → 描边”，不复制 Mesh，不替换原始材质数组，m_hir+ 高光不参与补绘。

HairCover 共用 Actor 光照、原贴图、骨架和 Morph；使用示例的头部朝向淡出公式，纹理 A 是淡出权重而非直接透明度。开关关闭时保留原有全透；“正面最低覆盖（补偿）”默认 0.35，设为 0 使用严格示例公式。已检查的琴音 PNG A 全白，严格公式正面可能仍全透，不能宣称已恢复原始遮罩。

语义映射、文章与仓库 ZWrite 差异、浏览器画布 Alpha 适配及验证范围见 `HAIRCOVER-MIGRATION.md`。原始顶点数据、RampAdd、Layer、完整游戏光照及专用 ShadowDepth 仍待后续实现。
